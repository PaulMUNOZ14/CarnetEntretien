Feuille de route

Où en est le projet, et où il va. Les versions à venir peuvent évoluer.

Version 1.0

Disponible
  • Gestion de plusieurs véhicules, modification et suppression
  • Historique des entretiens et règles de suivi (km / mois)
  • Tableau de bord à jauges, alertes « À prévoir » / « Urgent »
  • Prédiction des échéances d'après le kilométrage annuel
  • Recherche par plaque et photo du véhicule
  • Photo personnelle importée depuis l'ordinateur
  • Export CSV et installeur Windows autonome

Version 1.1

En préparation
  • Calendrier des entretiens
  • Suivi du contrôle technique
  • Historique kilométrique
  • Notifications Windows

Version 1.2

Prévu
  • Gestion des factures PDF
  • Suivi du carburant
  • Statistiques financières et graphiques de consommation
  • Comparaison entre véhicules

Version 2.0

Objectif
  • Sauvegardes automatiques, import / export JSON
  • Journal d'activité
  • API REST
  • Application mobile complémentaire
  • Synchronisation entre appareils et comptes utilisateurs

Une idée, un bug ?

Les contributions sont les bienvenues : ouvrez une issue sur GitHub pour signaler un problème ou proposer une fonctionnalité.
