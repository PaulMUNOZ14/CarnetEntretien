Installation

  1. Téléchargez l'installeur

    Fichier « Carnet Entretien » (.exe).

  2. Lancez-le

    Windows peut afficher un avertissement car l'application n'est pas encore signée : choisissez « Informations complémentaires » puis « Exécuter quand même ».

  3. Ouvrez l'application

    Au premier lancement, une fenêtre explique comment obtenir une clé pour la recherche par plaque (facultatif).

Pour les développeurs : lancer depuis le code source

Prérequis : JDK 21 ou supérieur. Maven n'est pas nécessaire, le mvnw inclus suffit.

git clone https://github.com/PaulMUNOZ14/CarnetEntretien.git
cd CarnetEntretien
./mvnw javafx:run

Pour lancer les tests (ils travaillent dans un dossier temporaire et ne touchent pas à vos données) :

./mvnw test

Pour fabriquer l'installeur Windows vous-même, utilisez le script creer-installeur.ps1 à la racine du projet (JDK 21+ avec jpackage requis).
